# moGSVA 与"逐组学 GSVA 后合并"的对照（基于当前 TCGA-BRCA 结果）

> 复现：`Rscript compare_naive_merge.R`，输出 `output/comparison_*.csv`。

## 一、对照的三种基线

| 代号 | 定义 | 说明 |
|---|---|---|
| **moGSVA** | `scores.csv`，Balanced 权重 + λ=0.25 一致性奖励 | 待评估方法 |
| **Merge (equal)** | 逐层 ES 的等权平均（有哪层算哪层） | 方法.md 中的 Baseline 1，最接近"单个组学 GSVA 结果合并" |
| **Merge (z-scored)** | 每层 ES 先按肿瘤 z 化再等权平均 | 常见的"先标准化再合并"变体 |
| **Pooled** | 拼接矩阵上直接做一次单组学 GSVA | 结果中自带的消融基线 |

## 二、主结果

在所有方法都能打分的 **285 条通路**上（ER：324 阳性 vs 101 阴性；OS：61 例死亡）：

| 指标 | moGSVA | Merge (equal) | Merge (z) | Pooled |
|---|---|---|---|---|
| ER 关联通路数（FDR<0.05） | 173 | **185** | 199 | 135 |
| ER 最小 q | 3.1e-27 | 2.8e-27 | 5.0e-27 | 6.4e-10 |
| OS 关联通路数（FDR<0.05） | 2 | 1 | 2 | 1 |
| 分数中位 \|ES\| | 0.095 | 0.102 | 0.503 | — |
| 逐通路 SD（中位） | 0.115 | 0.115 | 0.615 | — |
| 与 moGSVA 的逐通路 Spearman ρ（中位） | — | 0.994 | 0.969 | 0.50（Pearson） |
| 组学归因（哪一层在驱动） | **有** | 无 | 无 | 无 |
| 冲突量化（a / confidence） | **有** | 无 | 无 | 无 |

ER 命中重叠（335 条通路尺度的对照）：moGSVA 204 / Merge 219 / **共有 202**，
moGSVA 独有 2、Merge 独有 17；两法的 ER 效应量相关 r = 0.986。

## 三、把差异拆到两个设计组件上

`raw_scores.csv` 就是 λ=0 的加权平均，因此可以把差异拆开：

| 对比 | 逐通路 Spearman ρ（中位） | ER 命中 | 结论 |
|---|---|---|---|
| raw（Balanced 权重，λ=0）vs Merge（等权） | **0.9987** | 208 vs 219 | 权重规则几乎不改变排序 |
| fused（λ=0.25）vs raw（λ=0） | **0.9976** | 204 vs 208 | 一致性项也几乎不改变排序 |
| fused vs Merge | 0.994 | 204 vs 219 | 两者高度等价 |

即：**两个设计组件主要作用于"幅度"，而不是"排序"**。一致性奖励把分数中位
\|ES\| 从 0.090 压到 0.071（−21%），在组学互相矛盾的样本上压得更多：

| 一致度 a | 观测数 | merge / fused 幅度比 |
|---|---|---|
| 1（四层同向） | 40,550 | 1.00 |
| 0（正负各半） | 35,954 | 1.08 |
| −1/3（少数派反对） | 77,005 | 1.36 |
| −1（完全相反） | 589 | 1.67 |

两类分数在 **4.2%** 的通路×样本观测上符号相反；在 a<0.5 的 113,549 个观测里，
等权合并有 12,173 个仍给出 \|score\|>0.15 的"看起来确定"的活性，融合只有 7,464 个。

## 四、可以主张的优势（有数据支撑）

1. **组学归因是额外维度，而不是副产品。** `contributions.csv` 给出每条通路每个
   肿瘤里四层的贡献份额；主导层在肿瘤间并不稳定——每条通路中位出现 3 种不同的
   主导层，仅 1/335 条通路所有肿瘤主导层相同，42.3% 的观测由非众数层主导，
   份额的组内 SD 中位 0.304。任何固定 1/K 的平均都无法表达这一点。
2. **冲突被量化而非被平均掉。** 一致度 a 可以直接当作置信度字段：低一致度样本
   不再以"中等强度活性"出现，而是被显式标记并衰减（上表 1.36×/1.67×）。
3. **覆盖不均被显式处理。** 权重表给出每条通路每层的权重与 `skipped` 标记
   （蛋白仅覆盖 158/335 条通路）；等权平均隐含"有哪层算哪层且等价"。
4. **相对池化的实质提升（最强的一条）。** 同一批通路上 ER 命中 173 vs 135，
   最小 q 相差 17 个数量级；逐层还原度 0.46–0.82，而池化对甲基化是 **−0.20**、
   对蛋白只有 0.16（图 5C）。
5. **全流程可审计。** 权重规则、融合恒等式、贡献加和、一致度矩阵、p 值网格
   全部可复算（`output/evaluation_report.md`，最大偏差 ≤3e-16）；合并基线只给
   一个结果矩阵。

## 五、不能主张的三点（数据反对，写了会被审稿人打回）

1. **"融合的检出能力更强"** —— 同一批 285 条通路上 Merge 的 ER 命中反而更多
   （185 vs 173），效应量也更大（0.071 vs 0.058）。原因是全局衰减使 Wilcoxon
   统计量系统性变小，而不是信息丢失（两法效应量 r = 0.986）。
2. **"融合更均衡、不被单一层主导"** —— 在 156 条四层通路上，融合分数的方差预算
   是 CNA 4.1% / 甲基化 9.4% / 转录组 13.6% / **蛋白 72.8%**，等权平均则是
   8.5% / 18.5% / 27.7% / **45.4%**。Balanced 按成员数补偿（蛋白成员最少→权重最大），
   叠加蛋白层自身离散度最大（SD 0.28 vs 0.18–0.22），反而让融合更偏蛋白。
   这也解释了图 5C 中融合与蛋白层相关高达 0.82。
3. **"融合改变了样本排序、重构了活性谱"** —— 与合并的逐通路 ρ 中位 0.994，
   组件级分解后 ρ 仍 ≥0.9976；奖励项是乘性标量，排序几乎不变。

## 六、如果要把"优势"写实，建议这样表述与补实验

* **主张定位**：可解释（贡献分解）+ 可质控（一致度/置信度）+ 对覆盖不均与尺度
  差异透明；**检出能力**只在"与拼接池化"这一对手上做比较。
* **补一个 λ 消融**：λ=0 / 0.10 / 0.25 / 0.50 同表对比 ER、OS 命中数与效应量，
  直接量化一致性项的代价与收益（现有数据已可算出 λ=0：ER 208、OS 2）。
* **补权重敏感性**：`balance_feature_size=FALSE` 与 `FusionStrategy="Variance"`
  各跑一次，确认 ER/OS 结论不随权重方案翻转；若翻转，说明结论由蛋白层驱动。
* **若要主张生物学优势**：需要外部验证（CPTAC 蛋白基因组学）或生存/多变量模型，
  单变量 Wilcoxon 的命中数不适合作为"更好"的证据。
